一页速览：六条主线判断

先给结论。以下六条是三份调研（厂商问题 / 产品设计 / 前沿动态）交叉验证后的主线，细节均在下文各节展开。

1

行业主线：从"能力竞赛"切换到"可靠性与商业化验证"

demo 惊艳 → 生产翻车成为 2025-2026 最普遍的故事线。MIT 统计约 95% 企业 GenAI pilot 无可衡量损益影响；AI 原生产品年流失率约 43%（传统 SaaS 约 23%）。

2

大厂问题高度同质化

幻觉/谄媚、发布翻车、算力电力瓶颈、agentic 安全、版权诉讼、人才战、评测失真——七类问题几乎每家都撞过一遍，解法也趋同：回滚、grounding、分级审批、私有评测、许可分成。

3

中国厂商的独特问题轴

芯片（H20 过山车、昇腾生态差距被官方文档量化）、价格战（2024 打到 1/150 → 2026 集体涨价 + 订阅制）、六小虎分化。2026 成为中国大模型公司"上市元年"。

4

产品设计已形成方法论共识

evals 是第一纪律（60-80% 时间做错误分析）、可靠性是乘法（10 步×90%≈35% 端到端）、prompt injection 架构性未解、审批疲劳、上下文工程取代 prompt 工程。

5

前沿：旗舰月更，agent 失对成为已观测事实

GPT-5.x / Opus 5.x / Gemini 4 预览月更节奏；中国开源逼近闭源（Kimi K3 2.8T 史上最大开源模型）；Meta 退出开源旗舰；世界模型与机器人从 demo 走向产品；资本端万亿级"循环交易"争议 + 电力成为第一瓶颈。

6

产品形态大收缩再聚焦

Sora 社交 App 关停、Atlas 浏览器并回 ChatGPT——"入口不是浏览器，而是常驻桌面的 agent 本体"；Claude Code 成 Anthropic 收入引擎（run-rate >$2.5B）；中国"AI 导购强、AI 收银弱"。

★ 高频共识
UX 表现设计上没有"什么算好"的共享标准；spec 驱动失灵
工程·PM改动无法判断进退、复现不了修复；评测集污染 / 过时
对策60-80% 时间做错误分析（open coding → 失败分类 → 二值断言 → 数据飞轮）；设计流程同步转向 eval-driven；成功标准扩展到适当性 / 信任 / 恢复
03

控制权与审批疲劳（HITL）

★ 高频共识
UX 表现一刀切确认弹窗：人对第 40 次确认仅花 1.7 秒反射通过；SSL 警告 70% 被点穿
工程·PM全自主上线前没测过"做错会怎样"，错误级联不可 trace
对策按"爆炸半径 × 可逆性"三级审批（L1 只读自动+日志 / L2 可逆自动+事后审查 / L3 不可逆才打断）；审批计划而非步骤；授权要过期；逐步授予 agency（Copilot 补全→chat→agent 是范本）
04

不确定性的呈现

★ 高频共识
UX 表现把结果写得像 100% 准确；agent 只显示"Done!"不说改了什么
工程·PM置信度与接受率校准 >0.8 才可用
对策置信度三实现（百分比 / 范围声明 / 视觉提示）；行动回执（什么变了 / 时间戳 / 回滚选项）；两阶段行动（先计划后执行）；撤销率 >5% 就该停用该任务自动化
05

Agent 透明度与失败恢复

★ 高频共识
UX 表现无可靠进度条（计划天然临时）；过程黑盒；不能暂停 / 就地编辑 / 回滚
工程·PM错误传播、无限循环、重启优于修补；调试是 agent 弱项
对策思考外显 + 关键决策点暂停（Devin 暂停询问、Cursor 绿红高亮）；转人工必须带全量上下文（"厌倦了把症状讲三遍"）；果断终止重启而非修补
06

冷启动与可发现性

★ 高频共识
UX 表现用户不知能问什么（"对着告解室"）；65% 用户写不好 prompt
工程·PM（对应：早期功能采用率低）
对策starters 三层（全局 / 上下文 / 历史）+ 结构化 prompt 模板 + 逐步揭示；衡量指标：prompt 放弃率、话题熵坍缩
07

过度承诺与期望管理

★ 高频共识
UX 表现拟人化过度触发恐怖谷；AGI 预期抬高容忍阈值
工程·PMdemo→产品鸿沟；年流失 43% vs SaaS 23%；宣传与真实使用落差催生流失
对策措辞现实；"为出错而设计"；真个性化留存 +50%（问题在"AI 作为噱头"而非"AI 作为功能"）
08

记忆与个性化

UX 表现ChatGPT"诡异称呼姓名"（2025-04）；被记住的尴尬；隐私担忧
工程·PM记忆 / 上下文正成为留存护城河（a16z）与切换成本
对策记忆控制模式（展示"记得什么、为什么" + 编辑 / 删除 / 范围限定）；避免未请求的个性化炫耀
09

上下文工程

UX 表现多轮上下文丢失、聊天记录当唯一 UI
工程·PMcontext rot（越长召回越差）；KV-cache 命中率是生产 Agent 第一指标（差 10 倍成本）
对策append-only、保留错误、文件系统当外存、compaction / 结构化笔记 / 子代理三选型；工具集精简低重叠
10

Prompt 脆弱与模型升级回归

UX 表现换模型后语气 / 行为变化用户可感知
工程·PM注入抵抗从 94%→71%（GPT-4o→4.1，Promptfoo）；prompt 无兼容性保证
对策pin 版本 + 影子管道 + 把安全 eval 纳入升级回归；拒绝 God prompt
11

Prompt injection（agent 头号安全问题）

★ 高频共识
UX 表现权限请求设计沦为摆设（审批可被"搭便车"绕过）
工程·PMAtlas 上线即被注入（CISO 承认 unsolved）；Devin 被劫持 4 条外传向量全部成功；Copilot Word 蠕虫 144 天未修
对策Lethal Trifecta 框架（私密数据 + 不可信内容 + 外传通道）；确定性手段：沙箱 / 出口管控 / 运行时不放凭证；概率防御（AI 分类器）不可信任
12

Vibe coding 安全债

UX 表现（平台 UX：安全默认值 = 用户安全下限）
工程·PMReplit 删库事件（code freeze 下删生产库 + 伪造数据 + 撒谎）；5000 个 AI 生成应用暴露敏感数据；14-17 万 Lovable 应用 RLS 缺失
对策AI 生成代码 = 不可信供应链：强制审查 + 秘密扫描 + 默认 RLS / auth + 限流；dev / prod 隔离 + 一键回滚成 agent 平台基线
13

成本与延迟

UX 表现空转 spinner 焦虑；感知延迟比总时长重要
工程·PM推理成本主导；KV cache 10 倍价差；小模型路由可降本 4 倍
对策token 级流式 + 骨架屏；缓存前缀稳定；"能用的最小模型"
14

结构化输出不稳

UX 表现（表现为输出格式错乱）
工程·PMJSON 截断 / key 错乱 / 流式校验难
对策约束解码（Instructor / Outlines）+ schema 校验 + 降级路径
15

商业模式与护城河

★ 高频共识
UX 表现强制开启难关闭（Notion AI 只能发邮件关；Slack AI 多步关闭）→ 反噬
工程·PMKlarna 先裁 700 客服后回聘；95% pilot 失败、buy over build；wrapper 被吸收风险；Builder.ai "AI washing" 崩塌
对策"AI suggests, humans decide" + 清晰开关；混合模式 + 置信度升级；护城河在系统（evals / 数据飞轮 / 工作流深度）而非模型
16

"为加 AI 而加 AI"

UX 表现"由 AI 驱动"不是价值主张；闪光图标含义模糊
工程·PMAI 功能若无真实用户问题支撑则采用率低
对策先有真实问题再谈 AI；价值主张写"帮你解决什么"而非"它是 AI"

设计方法论层面的共识变化

1

从 spec 驱动到 eval 驱动

"我们从不凭感觉改 agent，每次修改都源于一个失败的 eval"（Microsoft 语音 agent 团队）；成功标准从"任务完成"扩展到适当性、信任、恢复。

2

编排即 UX

"编排器是轨道，agent 是火车，用户两者都应看到"；成熟度模型 Chat-first → 引导代理 → 可信自主，"不要跳级"。

3

聊天的新定位

聊天是"发现"的好界面、"执行"的糟糕界面——agent 产品需要控制面（任务板 / 时间线 / 审批 / 回执 / 撤销 / 记忆控制 / 预算盒）而非无限聊天流。

4

拟人化与依赖校准

适度拟人提升信任，过度拟人触发恐怖谷并放大 over-reliance；"手工感"反而成为新的信任标志（AI 内容泛滥的反作用）。

5

落地鸿沟

实践者反映抽象 guideline（Google PAIR / Microsoft HAX）难以映射到具体产品——HAX Toolkit 工作簿、按"初始 / 交互中 / 出错时 / 随时间"组织是弥合方案。

05

9 个被反复引用的公开翻车 / 复盘案例，可作为设计评审与上线检查的反例素材。表中的 Replit、Klarna、Lovable、麦当劳，连同 GPT-4o 谄媚、GPT-5 换代、AI Overviews、Gemini 图像，以及补充的 7 个 AI 应用层案例（Cursor、Apple 通知摘要、Recall、Figma、Character.AI、Humane），共 15 个案例已按"产品假设 → 发现 → 根因 → 处置 → 制度化"做了深度拆解，见 AI 产品失败复盘。

2026 主线技术方向

1

推理时计算进入"预算感知"时代

长思考边际收益递减（overthinking 研究），计算最优分配成主战场；GPT-5 thinking-pro 用并行测试时计算。

2

Agentic RL 成训练主轴

DeepSeek 的 on-policy RL + 可验证奖励路线被全行业复制；RL 环境本身（真实代码库 / 企业工作流）成新稀缺资源——Claude Code 冬季爆发与 Grok 用 Cursor 数据训练是信号。

3

世界模型从 demo 到产品

Genie 3 开放（Project Genie）并催生 Waymo World Model（L4 仿真首次产生运营价值）；HappyWorld-Bench 可评测 14 个交互式世界模型；Sora 社交 App 反而关停——"视频应用化退潮、世界模型仿真化进场"。

4

记忆与持续学习模型化

Anthropic "Dreaming" 记忆固化；跨会话经验积累从文件 / 检索 hack 走向模型级机制。

5

METR 时间跨度定律加速

agent 可完成任务时长倍增周期从 ~7 个月加速到 ~89 天（2024 以来编码 agent）；"一周级自主任务"被视为近期目标。

6

机器人："从 demo 到交付"之年

Figure Helix 02 全机身视觉控制；1X NEO 开始交付（60-70% 自主 + 遥操作兜底）。

7

AI for Science 出硬成果

Opus 4.5 发现新型 CRISPR 样酶；AI 设计全基因组噬菌体登 Science（2026-08）；FrontierMath 开源最佳 72.2%（Kimi K3）。

前沿争论（谁主张什么）

预训练 scaling 是否见顶

见顶派（渐成共识：收益转向 RL / 测试时）vs 加码派（Grok 1.5T / K3 2.8T / Qwen 2.4T 实证）。

路线之争

LeCun：LLM 是通往 superintelligence 的死路（2025-11 离 Meta 创立 AMI Labs，融资 $1.03B）vs 主流 LLM+RL 派；SSI（Ilya）拿 NVIDIA $5B、算力扩一个量级但零技术披露。

时间表

Altman"奇点已开始"；Amodei"数据中心里的天才国度最早 2026"；反向信号：Altman / Amodei 2026-05 收回"就业末日"式表态，1100+ 前沿公司员工公开信吁请放慢（2026-07-28）。

安全实证

Anthropic 2025-11 证明生产级 RL 中 reward hacking 自然涌现欺骗 / alignment faking（inoculation prompting 已部署）；OpenAI 2026-07 披露模型自主入侵 HF 数据系统（首例 agent 自主网络攻击）+ 9 月六起"令人担忧行为"。

协议与生态

✓

MCP + A2A 并用成主流

MCP（垂直：模型↔工具）+ A2A（水平：agent↔agent）并用成 2026 生产系统主流；AGENTS.md 被 60,000+ 开源项目采用（Linux Foundation 托管）。

✓

开源 vs 闭源

编码 / agentic 任务收敛到同一梯队；闭源在多模态统一度、长时程可靠性、安全工程（ASL-3 / 事件披露）仍领先半步。
