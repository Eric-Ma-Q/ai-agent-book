解读框架：产品经理怎么看一款 AI 产品

本报告对每款产品统一使用五个维度解构。核心判断：AI 本身不是产品，"用 AI 更好地完成某个具体任务"才是产品。所以每一款都回答——谁的、哪个具体任务，被它变得多快好省了。

🎯

目标用户

谁在用？消费者、开发者、创作者还是企业职能岗？用户群决定了付费能力与增长打法。

解决的问题

Job-to-be-done：原来这件事怎么做、贵在哪/慢在哪/难在哪？AI 把哪个环节的成本打下来了？

产品方案

订阅、用量计费、广告、API 还是成交分成？免费层怎么设计，钱从哪个环节收回来？

产品经理趋势洞察：从 111 款产品里读出的 9 条规律

1

入口之战换了方向：新浏览器退潮，桌面与消息应用上位

2026 上半年行业押注"AI 浏览器"（Atlas、Comet、Dia），但 Atlas 已于 8-09 停服并入桌面 App；真正跑出量的是两个旧容器：住在企微里的 WorkBuddy（3235 万月活）和住在 iMessage 里的 Instinct/Muse。结论被修正了一次——入口不是"新造一个浏览器"，而是"用户每天已经打开的那个窗口"。

2

所有产品都在 Agent 化，但"按结果付费"才是真拐点

从 Copilot Cowork、Claude Code 到 Sierra、Manus，产品形态从"对话给建议"变成"接任务给结果"。商业模式随之进化：Sierra 按解决量计费、Manus 按积分计费、Copilot 开始对 Agent 用量分层收费——"卖答案"正在变成"卖完成"。

3

编码是 AI 商业化最成功的赛道，没有之一

Cursor 年化 ~$4B、Claude Code 榜单领跑、GitHub Copilot 2000 万席位。原因：用户付费能力最强、ROI 可精确计算（省下的是工程师时薪）、反馈闭环最清晰。给创业者的启示：找"用户已经为解决这个问题花大钱"的场景切入。

4

广告成为 AI 的第二增长曲线

ChatGPT Ads 一年做到 $1B ARR 并全球扩张，Perplexity 在答案页试广告，Google 把广告搬进 AI Mode。"免费规模 + 广告"这套被验证 20 年的打法，正在 AI 上重演——订阅制 AI 产品将普遍面临免费+广告的降维竞争。

5

开源改写定价权：模型层通缩，应用层繁荣

DeepSeek、Kimi K3（2.8T MoE 开放权重）、FLUX.2（32B）把前沿能力做成公共品，模型 API 价格持续通缩。PM 层面的结论：不要再赌"我的模型更好"，要么做模型之上的工作流与数据壁垒，要么做模型之外的体验与分发。

6

版权从对抗走向交易，内容工业开始与 AI 共生

Suno 与 Warner 和解、Udio 与环球签约、Midjourney 与 Meta 达成分发合作——2026 年没有新增标志性诉讼，全是授权协议。预示着"授权分成"将成为 AI 内容产品的标准合规基础设施，先和解者先拿到商用市场门票。

7

企业市场：席位制的繁荣与"36% 使用率"的隐忧

Microsoft 20M 席位、Fortune 500 覆盖 90%+，但实际活跃使用率只有 ~36%；Claude 则靠安全叙事在企业采用率上反超 OpenAI。B 端 AI 的产品课：卖出去（license）和用起来（activation）是两场完全不同的仗，激活率会是下一轮续约谈判的核心变量。

8

中国打法：免费拿量、出海造血、硬件卡位

豆包 4.19 亿月活（投放+免费+语音降门槛）、可灵单月 $20M+ 收入（卖给电商与短剧）、MiniMax 海外收入占比 73%（Hailuo/Talkie 出海）、Manus 卖身 Meta、Kimi 模型进美国云——中国 AI 产品矩阵里，"量的战场在国内，钱的战场在全球"。

9

办公 Agent：AI 的第二张桌子，卖的是"交付"不是"回答"

QuestMobile 2026Q3：AI 办公赛道月活 1.42 亿、同比 +50.6%，PC 客户端用户同比 +512%。榜单是腾讯 WorkBuddy、百度搭子、千问办公——全是大厂。原因很直白：办公 Agent 需要组织上下文（聊天记录、文档、审批流），而这层数据只在大厂手里。对创业者，这一节的结论是负面的：通用办公 Agent 的机会窗口正在关闭，剩下的空间在"某个职能的深水区"。
