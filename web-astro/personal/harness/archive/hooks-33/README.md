# hooks-33 · 源文件

这个目录只放**源码**。发布页在项目根目录：`../claude-code-hooks-33.html`（和 index.html 里其它页面同级）。

| 文件 | 作用 |
| --- | --- |
| `build.py` | 33 个事件的数据、约束断言、HTML 生成 |
| `template.html` | 页面骨架（hero / 流程图 / 卡片 / 抽屉 / 自检区） |
| `style.css` | 全部样式 |

## 重新生成

```bash
cd hooks-33
python3 build.py      # 输出到 ../claude-code-hooks-33.html
```

构建时会先跑 5 条断言，任一不通过直接失败、不生成产物：

1. 33 个事件齐全、无重复、无拼写偏差
2. 10 个不支持 matcher 的事件没有写 matcher
3. 执行器类型落在各事件白名单内（5 类 / 4 类 / 3 类 / 2 类）
4. `if` 字段只出现在 5 个工具事件上
5. 配置片段每行 ≤ 70 字符（否则抽屉里会折行）

改文案或加事件时，改 `build.py` 里的 `hook(...)` 调用即可，断言会拦住写错的配置。
