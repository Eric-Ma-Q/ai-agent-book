05 / INFRASTRUCTURE把大脑与双手解耦：三大虚拟化组件

报告 05 的出发点近乎尖锐：harness 里写满了「模型做不到什么」的假设，而这些假设会过时（Sonnet 4.5 的 context reset 补丁，在 Opus 4.5 上成了累赘）。解法借鉴操作系统：拆成三个可独立替换的组件。

06 / CONSENSUS五条跨机构共识 + 七条施工清单

把 Anthropic、OpenAI、Lilian Weng 与学术界的材料并排放，五条结论被独立反复验证——点开每条看三条证据链。

Anthropic：抽象稳定

harness 假设会随模型过时，所以要「对实现不持立场」，接口先于实现。

OpenAI：深度耦合

极端重度投资单一 harness（Codex + 特定仓库结构），展示了这条路能走多远。

这不是矛盾，而是同一枚硬币的两面——产品级 harness 要抽象稳定，团队级 harness 可以深度耦合。

07 / DEEP DIVES三个深挖专题

🪜 自我改进阶梯 🧹 六条「什么不进窗口」路线 🔬 腐烂的五层证据链

🪜 优化对象的递进阶梯（Lilian Weng）

「自我改进」最近的发生地在 harness 层而非权重层——因为 harness 就是代码。每一级台阶点开看机制与数字。

🛡 护栏一：评测必须在循环之外——agent 不能改自己的考卷 🛡 护栏二：底座必须足够强——递归只放大已有能力 🛡 护栏三：档案与日志可审计——每一次进化可回溯

🧹 主动决定什么不进窗口：六条路线

十个跨机构实现收敛成六条路线，区别在「在哪个环节做决定」：入窗前、入窗时、临近上限、还是窗口之外。点卡片展开。

趋同信号一：70%——Gemini CLI 早期压缩阈值与 MemGPT 驱逐警告线相互独立、数值相同（Gemini CLI 现已下调到 50%） 趋同信号二：1,000–2,000 tok——子代理回传摘要的收敛量级 ⚠ 制衡：keep the wrong stuff in——错误轨迹是证据，激进清理等于销毁证据
