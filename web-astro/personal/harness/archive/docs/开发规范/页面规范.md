# 页面规范

> 适用于根目录全部 HTML 页面。颜色、间距等具体值以页面 CSS 变量为准，本规范只写约束与验收口径。

## 1. 交付形态

- **单文件**：CSS 与 JS 内联，每页可单独拷走或离线打开。
- **零外部运行时资源**：不引 CDN、远程字体、图标库、远程脚本；外部链接只用于正文引用与来源。
- **无构建**：除 `hooks-33` 生成页与 `_deck` 幻灯片外，页面直接手写，不引入打包器。

## 2. 主题（明暗）

- 两套 CSS 变量：`:root` 亮色、`html.dark` 暗色；颜色只通过变量引用，不在组件里写死色值。
- 脚本读取 localStorage `harness-theme`，无值时跟随 `prefers-color-scheme`；跨页监听 storage 事件同步。
- 例外：DeepSeek 篇用独立 `dsh-theme` 并自带切换按钮；`claude-code-hooks-33.html` 是深色单页，不参与主题同步。
- 切换按钮的 `aria-label`、`title` 随状态变化；`prefers-reduced-motion` 下关闭过渡动画。

## 3. 视口与长内容

- **375px 宽为最低验收宽度**，整页不得出现横向滚动。
- 表格外包滚动容器，沿用所在页面已有类名（`table-wrap`、`tablewrap`、`tblwrap`、`table-scroll`），不强制统一改名。
- 代码块、长 URL、宽图同样处理：`overflow-x:auto` 或 `overflow-wrap:anywhere`，禁止靠缩小字号硬塞。
- 断点按页面既有写法（常见 640px、800px）；新页面至少覆盖 640px 以下。

## 4. 排版与可访问性

- 中文字体栈：PingFang SC、Source Han Sans SC、Noto Sans SC、Microsoft YaHei；正文 15–16px，行高 1.7–1.85。
- 交互元素可键盘操作，`:focus-visible` 可见；有跳转链接（skip link）的页面保留。
- 暗色下正文对比度可读，不用纯黑底配纯白字。

## 5. 读者数据

- 只写 localStorage，键带版本后缀（如 `harness-exam:v1`）；读取失败静默降级，不阻塞页面。
- 提供导出或重置入口，并提示"仅保存在本机浏览器"。
- 不在页面里写死模型地址、密钥、内网地址。

## 6. 生成页

- **hooks-33**：模板 `template.html`、样式 `style.css`、数据与断言 `build.py` 分离；产物输出到仓库根目录，与 `index.html` 同级。
- 构建断言是门禁，失败即不产出；新增事件先补数据再跑断言，不为出产物放宽断言。
- **_deck**：`build_deck.py` 生成 pptx，产物与页面同级；版式检查用 `checks.json` 与 `qa_layout.py`。

## 7. 验收清单

- [ ] file:// 打开无报错，断网可用
- [ ] 375px 整页无横向滚动
- [ ] 明暗切换正常，刷新后偏好保留
- [ ] 键盘可操作，焦点可见
- [ ] 新增或修改的数字与 `index.html` 一致
