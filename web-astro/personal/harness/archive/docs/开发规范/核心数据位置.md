# 核心数据位置

> 项目里"数据"不指数据库，而是页面、内容来源、构建产物与读者本机状态。新增页面、换来源、改存储键时必须同步本表。

## 目录约定

- 根目录 `*.html`：交付物。每页单文件、离线、可直接拷走；`index.html` 是页面总览与登记处。
- `research/`：调研分册（01–18），是页面事实、数字、引语的上游来源；只增补与勘误，不因排版重写。
- `collab/`：生产流程存档。`tasks/`、`reports/`、`reviews/` 保留原貌；`BOARD.md` 是任务状态权威。
- `hooks-33/`、`_deck/`：生成页与幻灯片的源文件；根目录同名产物由脚本生成，不手改。
- `labs/`：可运行实验，代码与测试同目录；运行态写在各自被 gitignore 的目录（`.harness/`、`.selfloop/`）。
- `.playwright-mcp/`：浏览器调试产物（日志与快照），非权威、不参与交付。

## 数据索引

| 数据 | 读写代码 | 存储位置 | 格式 | 说明 |
|---|---|---|---|---|
| 页面清单 | `index.html` | 仓库根目录 | HTML 卡片 | 页面目录的权威来源；`pageCount` 按卡片数自动计算，分组与文案手写 |
| 调研分册 | `research/01`–`research/18` | `research/` | Markdown | 事实与出处来源；分册编号只增不改 |
| 协作任务状态 | `collab/BOARD.md` | `collab/` | Markdown 表 | 任务编号、状态、审核结论；交付报告在 `reports/`，审核意见在 `reviews/` |
| Hooks 页产物 | `hooks-33/build.py` | `hooks-33/`、根目录 `claude-code-hooks-33.html` | Python 生成 HTML | 33 个事件数据与 5 条断言在 `build.py`；断言失败不产出 |
| 技术分享幻灯片 | `_deck/build_deck.py` | `_deck/`、根目录 `.pptx` 与 `.pdf` | python-pptx 生成 | `checks.json`、`qa_layout.py` 用于版式与内容检查；PDF 在 `_deck/pdfout/` |
| mini-harness 代码 | `labs/mini-harness/harness/` | `labs/mini-harness/` | Python 标准库 | 测试在 `tests/`；模型地址、模型名、key 读 `HARNESS_*` 环境变量 |
| mini-harness 运行态 | `labs/mini-harness/harness/sessions.py`、`memory.py` | 工作区 `.harness/` | JSONL + Markdown | `.harness/sessions/` 是唯一真相源，`.harness/memory/` 是可由会话重建的派生缓存，勿手改 |
| SelfLoop 运行态 | `labs/selfloop/selfloop/archive.py` | `labs/selfloop/.selfloop/runs/` | 文件 | 每轮记录；已 gitignore，可删，不影响代码 |
| 主题偏好 | 各页内联脚本 | 浏览器 localStorage | 字符串 | `harness-theme`（全局）、`dsh-theme`（仅 DeepSeek 篇） |
| 答题记录 | `harness-exam.html`、`ai-pm-exam.html` | 浏览器 localStorage | JSON | 键 `harness-exam:v1`、`ai-pm-exam:v1`；含作答、成绩、错题本，可导出 JSON |
| 简历勾选进度 | `ai-pm-resume.html` | 浏览器 localStorage | JSON | 仅存本机；键在页面脚本内定义，改键需同步本表 |

## 维护规则

- 页面与代码不一致时以页面实际实现为准，立即改本表，不留"待确认"。
- 新增页面或分册时先加一行，再写内容；下线不删行，在说明里标"已下线"。
- 密钥、内网地址、模型名不写进任何文档与页面；需要时写"读环境变量"。
