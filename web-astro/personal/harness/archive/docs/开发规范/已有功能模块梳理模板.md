# 已有功能模块梳理模板

> 用于在 `docs/使用文档/已有功能模块梳理.md` 中添加新能力。只写"怎么用"，原理去模块实现文档。

```markdown
## [模块名称]
**路径**: `代码路径`（页面、构建脚本、实验分开写）
**文档**: [模块文档](../学习专题/NN-专题名称/README.md)（无则省略）

**快速使用**:
- **[场景1]**: [一句话说明怎么用]
- **[场景2]**: [一句话说明怎么用]
- **[场景3]**: [一句话说明怎么用]
```

填写要求：
- 快速使用 3-5 条，每条一句话，场景具体（页面、构建、脚本）。
- 不写原理和长篇解释；有详细文档就链接过去。
