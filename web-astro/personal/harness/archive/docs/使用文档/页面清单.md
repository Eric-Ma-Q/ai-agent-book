## 维护说明

- **权威性**：本表是页面信息的当前来源；`collab/ROADMAP.md` 的"已有内容"表是 2026-10-04 的快照，只作历史参考。
- **新增页面**：先在 `index.html` 对应分组加卡片，再在本表加行；卡片数即 `pageCount`，不需要手改数字。
- **内容来源**：优先写 `research/` 分册；外部一手来源写明类型；不确定的不写，不用"网上资料"凑数。
- **最后更新**：以文件修改日期为准；提交后可用 `git log -1 --date=short -- <文件>` 复核。
