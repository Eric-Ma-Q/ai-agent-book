# 已有功能梳理

> 可复用能力索引。只收"其他页面或脚本可以直接拿走复用"的东西；新增时按 [模板](../开发规范/已有功能模块梳理模板.md) 追加。

## 明暗主题切换

**路径**: `index.html` 内联脚本与 `:root` / `html.dark` 变量；`deepseek-harness-dsh.html` 为 `dsh-theme` 变体
**文档**: [页面规范](../开发规范/页面规范.md)

**快速使用**:
- **新页面**：复制两套 CSS 变量与主题脚本，保留 `#themeFab` 按钮结构与图标。
- **键名**：统一用 `harness-theme`；DSH 篇才用 `dsh-theme`，不要给单个页面另起键名。
- **跟随系统**：无保存值时读 `prefers-color-scheme`，并监听其变化。
- **跨页同步**：监听 `storage` 事件，保证标签页之间切换一致。

## 页面骨架与卡片网格

**路径**: `index.html` 的 `<style>` 与 `<main class="wrap">` 结构
**文档**: [页面规范](../开发规范/页面规范.md)

**快速使用**:
- **目录页**：复制 `.wrap`、`.group`、`.grid`、`.card` 四组样式与对应结构。
- **分组语义**：每组用 `section` 加 `aria-labelledby`，标题下配一句 `gdesc`。
- **卡片信息**：用 `.meta` + `.chip` 列类型、数量与状态，避免长段描述。
- **移动端**：网格在 640px 以下自动单列，新增卡片后要复查。

## 表格横向滚动容器

**路径**: `ai-expense-review-prd.html`（`.table-wrap`）、`ai-agent-pm-career.html`（`.tablewrap`）、`ai-harness-explained.html`（`.tblwrap`）、`ai-failure-casebook.html`（`.table-scroll`）
**文档**: [页面规范](../开发规范/页面规范.md)

**快速使用**:
- **包一层**：表格外包 `div`，类名沿用所在页面已有的滚动类，不强制统一改名。
- **样式**：容器 `overflow-x:auto`，表格设 `min-width`，避免挤压列宽。
- **同类内容**：代码块、长 URL、宽图同样处理。
- **验收**：375px 宽检查整页不出现横向滚动，而不是只看表格本身。

## hooks-33 构建与断言

**路径**: `hooks-33/build.py`、`hooks-33/template.html`、`hooks-33/style.css`
**文档**: [hooks-33 说明](../../hooks-33/README.md)

**快速使用**:
- **重新生成**：`cd hooks-33 && python3 build.py`，输出到根目录 `claude-code-hooks-33.html`。
- **改内容**：只改 `build.py` 里的 `hook(...)` 数据与文案，产物不手改。
- **断言**：5 条断言失败即不产出，先修数据而不是删断言。
- **加事件**：同步中文名、触发时机、执行器白名单与是否支持 matcher。

## SelfLoop 验证循环

**路径**: `labs/selfloop/selfloop/`（`loop.py`、`verify.py`、`archive.py`、`providers.py`、`server.py`）
**文档**: [SelfLoop 说明](../../labs/selfloop/README.md)

**快速使用**:

- **运行态**：`.selfloop/` 已 gitignore，可删；不要把它当交付物。
