# 文档体系说明

本项目是离线单文件学习站点：根目录 HTML 是交付物，`research/` 是内容来源，`collab/` 是多智能体生产流程的存档。文档只记"从代码和页面里看不出来的事"：边界、来源、口径、为什么这样做、怎么验证。

## 1. 开发规范 (`开发规范/`)

- [开发流程](./开发规范/开发流程.md)：改页或加页前查什么、收尾更新什么（入口）
- [核心数据位置](./开发规范/核心数据位置.md)：页面、调研分册、构建产物、读者数据分别在哪
- [页面规范](./开发规范/页面规范.md)：单文件离线、主题、375px 视口、可访问性、生成页
- [业务模块文档模版](./开发规范/业务模块文档模版.md)：本项目"业务模块"指一个学习专题（复杂页面/实验）
- [已有功能模块梳理模板](./开发规范/已有功能模块梳理模板.md)：往可复用能力索引里追加条目时用

## 2. 使用文档 (`使用文档/`)

- [页面清单](./使用文档/页面清单.md)：各学习页面的入口、分组、来源、构建方式、最后更新
- [已有功能模块梳理](./使用文档/已有功能模块梳理.md)：主题脚本、页面骨架、构建断言等可复用片段

## 3. 学习专题 (`学习专题/`)

- [专题索引](./学习专题/README.md)：Hooks33 事件、SelfLoop 自举循环、Harness 结业考试、AI 产品经理考试
- 只给有构建脚本、状态机或判分逻辑的页面建专题；其余页面在页面清单登记即可。

## 4. 临时 (`临时/`)

交接、走查、一次性计划。文件名带日期；事情结束后并入正式文档或删除，不放长期规则。

## 5. 站点入口

- [index.html](../index.html)：全部页面总览，也是新增页面的登记处；卡片数为页面数的权威来源。
