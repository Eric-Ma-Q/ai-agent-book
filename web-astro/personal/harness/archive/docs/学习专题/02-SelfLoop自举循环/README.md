## 核心内容

1. **四道闸门**：可见测试 35%、隐藏用例 65%、canary 只判 verified、完整性检查防作弊；证据由机器产生，不采信模型自述。
2. **诚实停机**：verified、预算、连续平台期、最大轮数四种终止条件，全部写在代码里，不依赖提示词。
3. **可回放档案**：每轮候选连同分数、闸门明细、源码快照与事件流落盘，失败候选保留为负样本。
4. **默认模拟模式**：离线、确定、零成本，先看懂整条链路，再决定是否接真实模型。
