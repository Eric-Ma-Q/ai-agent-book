# SelfLoop 自举循环实现文档

## 一、架构概览

- **启动入口**：[labs/selfloop/run.py](../../../labs/selfloop/run.py)，解析 host、port、runs 目录后启动本地服务。
- **循环控制**：[loop.py](../../../labs/selfloop/selfloop/loop.py)，负责提议、验证、闸门、归档与停机。
- **验证器**：[verify.py](../../../labs/selfloop/selfloop/verify.py)，在一次性临时目录里跑分并产出机器证据。
- **档案库**：[archive.py](../../../labs/selfloop/selfloop/archive.py)，落盘运行元数据、候选、源码快照与事件流。
- **提议者**：[providers.py](../../../labs/selfloop/selfloop/providers.py)，提供离线 MockProposer 与 OpenAI 兼容的 OpenAIProposer。
- **任务定义**：[tasks.py](../../../labs/selfloop/selfloop/tasks.py)，参考实现、可见测试、隐藏用例与 canary 的契约。
- **服务与前端**：[server.py](../../../labs/selfloop/selfloop/server.py) 与 `web/`，REST + SSE，零构建原生 JS。

## 二、核心逻辑

1. **每轮闭环**：提议者产出一个完整 Python 文件；验证器在沙箱里跑可见测试、隐藏用例、canary 与完整性检查；只有严格变好才更新最优解，否则只入档；随后写入候选、快照与事件。
2. **四道闸门**：
   - 可见测试占 35%，只给模型看失败项；
   - 隐藏用例占 65%，随机与边界输入，期望值由参考实现生成；
   - canary 用分布不同的退化输入，只参与 verified 判定，不影响分数；
   - 完整性禁止文件读写、子进程、`eval`、反射，并要求测试文件哈希不变。
3. **停机条件**：verified（默认开启）、费用超预算、连续 K 轮无提升、达到最大轮数。终止条件是代码，不依赖提示词。
4. **提议者边界**：MockProposer 按脚本逐轮修好函数，离线确定；OpenAIProposer 读 `SELFLOOP_BASE_URL`、`SELFLOOP_MODEL`、`SELFLOOP_API_KEY`，只接收可见失败与聚合分数，不接收隐藏用例。密钥只存在内存，`RunConfig.to_dict()` 会移除 `api_key`，不落盘、不出现在 API 响应。
5. **档案结构**：`.selfloop/runs/<run_id>/` 下含 `meta.json`、`candidates.jsonl`、`snapshots/<id>.py`、`best.py`、`events.jsonl`；失败候选与原因保留，便于回放与复盘。

## 三、数据边界

- **读取**：`tasks.py` 的参考实现与用例；真实模型模式下读 OpenAI 兼容端点；费用单价读 `SELFLOOP_PRICE_IN` / `SELFLOOP_PRICE_OUT`。
- **写入**：仅 `.selfloop/runs/`（默认在启动目录下，已 gitignore）；不改动仓库源码，不写用户工作区。
- **上游**：无服务依赖；验证器自包含。
- **下游**：本专题文档、页面清单与 README 中的运行说明。
- **项目级约束**：零第三方依赖；密钥只走环境变量；候选代码不得读写文件或起子进程；运行态可删，不作为交付物。

## 四、交互与配置

| 入口 | 位置 | 作用 | 说明 |
| --- | --- | --- | --- |
| 开始 / 暂停 / 继续 / 停止 | 页面控制区 | 控制循环 | POST `/api/start`、`/api/pause`、`/api/resume`、`/api/stop` |
| 任务与模式 | 启动参数 | 选任务与提议者 | 默认 `intervalkit` + `mock`；真实模式需 key |
| 轮数 / 预算 / 平台期 | 启动参数或请求体 | 控制停机 | 默认 10 轮、2 美元、连续 3 轮无提升 |
| 历史运行 | 页面列表 | 查看历次状态与候选 | GET `/api/runs`、`/api/run/<id>` |
| 候选 diff | 右栏 | 对比候选与最优解 | GET `/api/candidate/<id>/<n>` |
| 静态模式 | URL 参数 `?static=1` | 关闭 SSE，退化为拉取 | 截图与调试用 |
| 自动选中 | URL 参数 `&select=last` | 选中最后一轮并展示 diff | 截图与分享用 |

## 五、验证方式

- **自动化**：`cd labs/selfloop && python3 -m unittest discover -s tests -v`，当前 14 项通过。
- **手工**：`cd labs/selfloop && python3 run.py`，浏览器开本机 8791 端口；用默认模拟模式跑一轮，确认分数从基线上升、候选被接受、最终 verified 或按条件停机；查看 diff 与闸门明细；结束后关闭服务。
- **数据**：检查 `.selfloop/runs/<run_id>/` 的 `meta.json`、`candidates.jsonl`、`best.py`、`events.jsonl` 是否一致；确认 `api_key` 未出现在任何落盘文件与 API 响应中。
