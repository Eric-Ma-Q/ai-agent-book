## 核心内容

1. **试卷结构**：7 个部分（A 概念快答到 G 开放论述），97 题、294 分，覆盖 18 个专题与 6 个能力层级。
2. **三种模式**：正式考试全卷计时；练习模式逐题核对；错题重练只出未掌握的题（连续答对两次才算掌握）。
3. **判分口径**：单选与判断全对得分；多选/代码诊断错选不得分、少选得一半；填空按空计分；排序按相对顺序比例；连线按对数；开放题按评分细则自评。
4. **学习闭环**：专题与层级掌握度报告、薄弱专题重读建议、错题本、导出 Markdown 交给 AI 批改或导出 JSON 备份。
