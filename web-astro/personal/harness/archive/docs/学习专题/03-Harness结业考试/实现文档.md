# Harness 结业考试实现文档

## 一、页面结构

- **页面文件**：[harness-exam.html](../../../harness-exam.html)，单文件、离线、无构建。
- **三段视图**：`introView`（试卷结构、模式选择、历次成绩）、`examView`（答题与计时）、`reportView`（成绩单与解析）。
- **内联数据**：`TOPICS`（18 个专题）、`LEVELS`（6 个层级）、`PARTS`（A–G）、`Q`（97 道题）。
- **样式与脚本**：全部内联；主题沿用全局 `harness-theme`，与站点其他页面同步。

## 二、核心逻辑

1. **题库结构**：每题含 `id`、`part`、`type`、`topic`、`level`、`pts`、`stem`，按题型追加 `options`/`answer`/`blanks`/`left`/`right`/`rubric`，以及 `explain` 与 `src`。当前 97 题、294 分、18 个专题、6 个层级；题型 8 种：填空、判断、单选、多选、排序、连线、代码诊断、开放论述。
2. **组卷与模式**：
   - 正式考试：全卷、计时，交卷后统一判分；
   - 练习模式：逐题核对，立即显示对错与解析；
   - 错题重练：只抽 `mistakes` 中 `streak < 2` 且非开放题的题目；连续答对两次移出错题本。
   - 未交卷草稿可恢复；开始新考试会放弃旧草稿。
3. **判分**：`grade(q, ans, selfIdx)` 统一入口。
   - 单选、判断：全对得分，否则 0；
   - 多选、代码诊断：错选为 0，选全得满分，少选得一半；
   - 填空：按空计分，答案做大小写、空白、标点与"约/大约"归一；
   - 排序：按两两相对顺序正确的比例计分，低于一半记 0；
   - 连线：按正确对数计分；
   - 开放题：按 `rubric` 逐条自评，未勾选标 `pending`。
4. **报告**：按 `topic` 与 `level` 聚合得分；专题掌握度低于 75% 的取最弱 4 个给重读建议；条形图中低于 60% 标"弱"；开放题未自评时总分标注"待自评"，提示先自评或导出批改。
5. **存储**：键 `harness-exam:v1`，结构含 `draft`、`attempts`（最多 30 次）、`mistakes`（`wrong`、`lastWrong`、`streak`）。作答防抖 250ms 落盘；解析失败降级为空档案并提示存储不可用。
6. **选项乱序**：按题目 id 生成固定种子打乱选项，存储的始终是原始下标，显示字母随打乱顺序映射；刷新后顺序稳定，避免背字母。

## 三、数据边界

- **读取**：题库、专题、层级、部分说明全部内联在页面；解析里的 `src` 指回站内页面或外部来源。
- **写入**：仅浏览器 localStorage `harness-exam:v1`；不发起网络请求，不上传作答。
- **上游**：Harness 深读四页与 `research/08`–`research/14`；题目内容不在运行时读取这些文件。
- **下游**：[index.html](../../../index.html) 卡片、[页面清单](../../使用文档/页面清单.md) 的题量与最后更新。
- **项目级约束**：单文件离线；主题键不另起；存储失败不得阻塞答题。

## 四、交互与配置

| 入口 | 位置 | 作用 | 说明 |
| --- | --- | --- | --- |
| 模式选择 | 首页 | 正式 / 练习 / 错题重练 | 错题本为空时禁用错题重练 |
| 开始 / 继续 | 首页 | 新建或恢复作答 | 草稿含模式、题序、答案、用时 |
| 核对 | 练习模式题卡 | 单题判分并显示解析 | 只影响当前题，不改变正式成绩 |
| 交卷 | 答题页 | 统一判分并生成报告 | 开放题进入待自评状态 |
| 开放题自评 | 报告页 | 按细则勾选得分点 | 可多次调整，总分实时更新 |
| 错题重练 | 首页 | 只出未掌握题 | 连续答对两次移出 |
| 导出给 AI 批改 | 报告页 | 复制 Markdown | 含题目、作答、评分细则与专题掌握度 |
| 导出 JSON | 报告页 / 首页 | 下载单次或全部记录 | 用于备份与迁移 |

## 五、验证方式

- **自动化**：未补充脚本；题库统计可用页面脚本或一次性脚本核对。
- **手工**：
  - file:// 打开，确认 97 题全部渲染、7 个部分题数与分值合计 294；
  - 正式考试全选正确答案应得满分；错选、少选、空白分别命中对应判分分支；
  - 练习模式单题核对、错题重练、草稿恢复、交卷报告与导出均可用；
  - 375px 宽无横向滚动；明暗两态正常；刷新后作答与成绩仍在。
- **数据**：检查 localStorage 中 `harness-exam:v1` 的 `draft`、`attempts`、`mistakes` 结构与页面注释一致；`attempts` 不超过 30 条。
- **历史记录**：[collab/BOARD.md](../../../collab/BOARD.md) 记载 2026-10-05 曾用 CDP 对 91 题做过点击级测试；当前 97 题未重跑该脚本，以上手工项为准。
