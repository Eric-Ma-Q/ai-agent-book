# Harness 结业考试内容文档

## 一、学习目标

- 能独立完成 97 道题，并解释每类题的判分口径，知道哪些分是"机器给的"、哪些是"自己评的"。
- 能读懂交卷报告：专题掌握度、层级掌握度、薄弱专题与重读建议分别说明什么。
- 能用错题重练把薄弱专题补到 75% 以上，并说清"连续答对两次"为什么比"看过解析"更可信。
- 能把开放题导出给 AI 批改，判断批改意见是否站得住。

## 二、目标读者

- 读完 [Harness 深度解读](../../../ai-harness-explained.html)、[交互流程图解](../../../ai-harness-flow.html)、[DSH 篇](../../../deepseek-harness-dsh.html) 与 [Harness 工程](../../../harness-engineering.html) 的读者。
- 想检验自己是否真的理解核心循环、上下文工程、工具、安全、记忆、多智能体、评测与成本的人。
- 带团队做 harness 培训、需要一套可自测题库的人。

## 三、知识边界

- 不替代原文：题目只抽查关键结论与判断，完整论证仍在各页面与 `research/08`–`research/14`。
- 数字与结论以出题时的页面和分册为准；行业数据会过期，答对不等于当前仍然成立。
- 开放题没有唯一答案，评分细则用于自评，不作为客观标准。
- 不覆盖 DSH 插件开发、Claude Code 全部配置项等实现细节；这些属于对应专题。

## 四、来源与核实

- 出题依据、题目出处写在每题的 `src` 字段，交卷后的解析会带原文链接。
- 主体来源：Harness 深读四页 + `research/08`–`research/14` 七份分册 + `labs/mini-harness` 实验。
- 2026-10 新增的工程专题覆盖横评拆解、MCP、安全、记忆、多智能体、评测、成本与动手实验。
- 题目数字（97 题、294 分、18 专题）由页面题库数据统计，改动题目后需重新核对 [页面清单](../../使用文档/页面清单.md) 的最后更新与 `index.html` 卡片文案。

## 五、可延展的设想

- 按分册组卷：允许只考某一份分册，降低整卷 60–75 分钟的门槛。
- 案例题扩充：把失败案例集里的真实故障改造成诊断题。
- 错题导出：支持导出为间隔复习格式，而不只是重练。
- 难度自适应：按上一轮专题掌握度自动调整题量与层级。
