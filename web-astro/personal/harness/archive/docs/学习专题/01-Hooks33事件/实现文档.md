# Hooks33 事件实现文档

## 一、页面结构

- **页面文件**：根目录 [claude-code-hooks-33.html](../../../claude-code-hooks-33.html)，由脚本生成，不手改。
- **页面骨架**：[hooks-33/template.html](../../../hooks-33/template.html)，含 hero、值班流程图、33 张事件卡、自检区、完整配置、抽屉。
- **样式**：[hooks-33/style.css](../../../hooks-33/style.css)，深色单页，全量内联进产物。
- **构建脚本**：[hooks-33/build.py](../../../hooks-33/build.py)，负责事件数据、约束断言与模板渲染。

## 二、核心逻辑

1. **事件数据**：33 个 `hook(event, phase, cap, matcher, htype, role, snippet, detail, entry)` 调用，按 6 个阶段组织：冷启动、入场、工具循环、并发面、收口、退场。每条含中文说明、真实配置片段、入口配置与能力标注。
2. **构建断言**：`check()` 收集错误后统一失败，非零退出且不写产物。检查项包括：
   - 事件数 33、无重复、与 `ALL_EVENTS` 集合一致；
   - `NO_MATCHER` 事件不得配 matcher，其余事件必须配；
   - 执行器类型落在该事件白名单内（5 类 12 个、4 类 1 个、3 类 18 个、2 类 2 个）；
   - 决策能力标注与官方文档一致（可干预 / 仅注入 / 仅观测）；
   - `if` 字段只出现在工具事件；SessionStart 与 Setup 不得用启动时不可用的 `mcp_tool`；
   - 配置片段单行不超过 70 字符，避免抽屉折行；分区覆盖全部事件且互不重叠。
3. **渲染**：读取 `style.css` 与 `template.html`，替换 `{{CSS}}`、`{{FLOW}}`、`{{PHASES}}`、`{{SETTINGS}}`、`{{CONTROL_TABLE}}`、`{{TYPE_TABLE}}`、`{{HOOK_DATA}}` 等占位，输出到 `../claude-code-hooks-33.html`；流程图 SVG 与 33 张卡片由同一份数据生成。
4. **交互**：流程图节点点击打开右侧抽屉，展示中文名、触发时机、执行器类型、能力与配置；抽屉内"上一个 / 下一个"沿生命周期连续翻看；支持 Tab 聚焦加回车打开、Esc 关闭，并可跳到下方对应事件卡。

## 三、数据边界

- **读取**：官方能力表（转写为脚本内的常量集合）；`template.html`；`style.css`。
- **写入**：根目录 `claude-code-hooks-33.html`，每次构建覆盖。
- **上游**：Claude Code 官方 hooks 文档；事件能力以官方为准，脚本不自行扩展。
- **下游**：[index.html](../../../index.html) 的卡片、[页面清单](../../使用文档/页面清单.md) 的登记。
- **项目级约束**：单文件离线、零外部资源；深色固定页面，不读取 `harness-theme`，不参与主题同步。

## 四、交互与配置

| 入口 | 位置 | 作用 | 说明 |
| --- | --- | --- | --- |
| 流程节点 | 值班流程图 | 打开对应事件的抽屉 | 颜色区分为可干预 / 仅注入 / 仅观测 |
| 上一个 / 下一个 | 抽屉底部 | 沿生命周期翻看 33 个事件 | 不跨阶段跳转，顺序与时间线一致 |
| 键盘 | 页面 | Tab 聚焦、回车打开、Esc 关闭 | 焦点样式跟随页面既有规则 |
| 事件卡片 | 33 事件区 | 直接查看该事件的配置与说明 | 与抽屉同源数据 |
| 完整配置 | 页面后段 | 查看合并后的 `settings.json` | 由断言校验后的数据生成 |

## 五、验证方式

- **自动化**：`cd hooks-33 && python3 build.py`。构建先跑断言，通过后打印 5 行结果并写产物；任一断言失败则非零退出且不生成页面。
- **手工**：file:// 打开页面；依次点开 33 个节点，确认抽屉内容与卡片一致；用键盘走一遍打开与关闭；在 375px 宽确认无横向滚动；确认深色下正文与代码可读。
- **数据**：核对事件数 33、事件名唯一；20 可干预 / 4 仅注入 / 9 仅观测；执行器分区 12 + 1 + 18 + 2；配置片段最长行不超过 70 字符。
