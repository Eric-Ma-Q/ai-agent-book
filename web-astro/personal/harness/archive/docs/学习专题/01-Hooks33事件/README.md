## 核心内容

1. **事件全集**：33 个事件按 6 个阶段排进同一晚迁移（02:00 冷启动到 05:00 退场），一个不多、一个不少。
2. **能力边界**：20 个可干预、4 个仅注入、9 个仅观测；执行器按事件分 5 类、4 类、3 类、2 类白名单。
3. **构建门禁**：事件完整性、matcher 白名单、执行器白名单、决策能力标注、`if` 字段与配置行宽，任一不通过就不产出页面。
4. **阅读路径**：先看值班流程图，再点开抽屉逐条看真实配置，最后用自检区与完整 `settings.json` 复核。
