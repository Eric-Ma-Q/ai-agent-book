# T04 · 记忆系统：agent 怎么"记得"，又怎么"忘掉"

**模块**：M4　**类型**：调研写作　**优先级**：高

## 目标
讲清 harness 的记忆层：哪些东西该记、记在哪、什么时候读、怎么更新和遗忘、怎么防止记忆被污染。产品形态的横评 08 分册 §3.6 已经做过，**本篇不重复横评**，重点放在机制、研究和设计取舍上。

## 覆盖范围
1. **记忆分类学**：工作记忆（上下文窗口）/ 情景记忆（会话历史）/ 语义记忆（事实、偏好）/ 程序记忆（技能、规则）。各家和学界的分法对照。
2. **存储与检索形态**：纯文件（AGENTS.md、MEMORY.md 索引 + 正文）、结构化存储（Letta/MemGPT 的分层记忆、Mem0、Zep / Graphiti 时序知识图谱）、向量检索、Anthropic memory tool（API 级记忆工具）、OpenAI ChatGPT memory。各自适合什么场景。
3. **写入策略**：谁决定写（模型自主 / harness 规则 / 用户显式）、写什么（事实 vs 过程 vs 反馈）、什么时候写（实时 / 会话结束 / 压缩时），如何去重和合并。
4. **遗忘与更新**：过期、冲突、版本化；"记忆腐烂"的公开案例。
5. **记忆安全**：记忆投毒、持久化注入（一次注入、长期生效）、跨会话数据泄露的公开研究和事件。
6. **评测**：LongMemEval、LoCoMo 等记忆评测基准，结论是什么，可信度如何。

## 必须回答的问题
1. 2026 年编码 agent 的主流是"文件型记忆"而不是"向量数据库记忆"，为什么？什么场景下向量 / 图谱记忆才值得上？
2. 记忆写入由模型自主决定，最常见的失败方式是什么？有什么公开数据或案例？
3. 持久化记忆让提示注入从"一次性"变成"长期驻留"，目前有哪些防御做法？
4. 给出一份 **harness 记忆层设计清单**（≥ 12 条），覆盖分类、写入、读取、遗忘、安全、可审计。
