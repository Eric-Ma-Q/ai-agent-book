## 摘要

1. **分类学收敛于认知科学四分法**：CoALA（working/episodic/semantic/procedural）是 LangGraph、Letta 等工程文档的共同引用源头；产品界没有一家明着做"情景记忆"——经历必须被陈述化成"事实句"才能在文件型存储里存活。
2. **文件型记忆是 2026 编码 agent 的主流，且证据链完整**：Claude Code（索引+正文）、Codex（`~/.codex/memories/`）、Anthropic memory tool（客户端 `/memories`）、Manus（"文件系统是终极上下文"）全部落文件；**连 MemGPT/Letta 自己的当前文档（2026-10 抓取）都已把 core/recall/archival 三层换成 git 版本化的 MemFS + Dreaming 后台整理**——这是本次调研最有分量的新发现。
3. **文件型在基准上不输专门记忆层**：Letta 用"纯文件+grep/open/close+GPT-4o-mini"在 LoCoMo 拿 74.0%，超 Mem0 论文最优的 68.5%；Mem0 自己论文的表格里全上下文基线（约 72.9%）也高于 Mem0（约 66.9%）。
4. **写入策略的行业共识是"别让模型在热路径随手写"**：Codex 后台批处理+独立整合模型+跳过短会话+自动脱敏；Mem0 用 ADD/UPDATE/DELETE/NOOP 四操作比对补救自主写入；Letta 的 Dreaming 把整理挪到空闲期。
5. **模型自主写入最常见的失败**：噪声写入（Codex/Mem0 的复杂度即官方承认）、该更新不更新（LongMemEval 知识更新维度商业助手整体掉约 30%）、重复冲突并存、被注入操控（SpAIware，2024-09，OpenAI 修复）、敏感信息入库。
6. **记忆把提示注入变成"长期驻留"**：AgentPoison 证明 <0.1% 投毒率、>80% 攻击成功率、良性影响 <1%；防御开始成形——"会话含外部不可信内容就禁写"（Codex `disable_on_external_context` 官方先例）、脱敏、记忆当不可信输入读、用户可见可逆、记忆≠规则分层。
7. **记忆基准正打"基准大战"，横向分数不可信**：Zep 复测 Mem0、Letta 拆台、Penfield Labs 审计出 LoCoMo 约 6.4% 标准答案有错且 judge 会把 63% 的错误答案判对；纵向能力分项可信——"知识更新"与"选择性遗忘"是无人及格的考题。
8. 产出 **16 条 harness 记忆层设计清单**（分类与结构 4 / 写入 4 / 读取 3 / 遗忘与更新 3 / 安全与可审计 2），全部有出处或明确标【推断】。
