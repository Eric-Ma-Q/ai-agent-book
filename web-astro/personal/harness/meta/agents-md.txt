1. 沟通与文档风格：中文、结论先行，能一句说清不写三句；文档不写 emoji，不重复表述。
2. 环境：macOS + zsh，Python 以标准库优先；命令按 macOS 写，路径一律相对仓库根并用 `/`。
3. 禁止：不主动 git commit / push，用户明确要求才提交；不装依赖，只给安装命令；不删除已有页面与调研分册。
4. 预览入口：页面直接 file:// 打开 index.html；需要 HTTP 时自行起 `python3 -m http.server` 并在结束时关闭；labs/selfloop 用 `python3 run.py` 起 8791 端口，用完关闭。
5. 页面是单文件离线资产：不引外部 CDN、字体、图标库或远程脚本，断网可打开。原因：交付形态就是可拷走的单文件；细则见 `docs/开发规范/页面规范.md`。
6. 375px 宽不得横向滚动：表格、代码块、长 URL 必须包进 overflow-x:auto 容器。原因：F03 返工就是表格溢出；细则见 `docs/开发规范/页面规范.md`。
7. 生成页只改源：claude-code-hooks-33.html 由 hooks-33/build.py 生成，改源后重跑；手改产物会被覆盖并绕过断言；细则见 `docs/开发规范/页面规范.md`。
8. 构建断言是交付门禁：hooks-33 的 5 条断言失败即不产出，不得为出产物删断言或注释检查；数据与断言见 `hooks-33/README.md`。
9. 主题键固定：全局 `harness-theme`，DSH 篇 `dsh-theme`；改名会让读者已保存的明暗偏好失效；键表见 `docs/开发规范/核心数据位置.md`。
10. 数字必须同步：新增页面更新 index.html 卡片与分组，题量/案例数变化同步卡片文案与页内说明（T10 后出现过期数字）；登记见 `docs/使用文档/页面清单.md`。
11. 不写死密钥、内网地址、模型名：labs 的模型地址与 key 一律读环境变量。原因：仓库会分发和上传，写死等于外泄；变量名见 `docs/开发规范/核心数据位置.md`。
12. 改页或加页前先读 `docs/开发规范/开发流程.md`，按"准备阶段"查页面清单与数据位置；不读会重复造轮子或改错产物。
13. 动视觉或交互前读 `docs/开发规范/页面规范.md`；有构建脚本、状态机或判分逻辑的页面按 `docs/开发规范/业务模块文档模版.md` 建专题文档。
14. 完成标准：页面改动须同步 `docs/使用文档/页面清单.md` 的"最后更新"和相关专题文档；验证至少覆盖浏览器打开、375px 无横向滚动、明暗两态、控制台无报错，并写明跑过的命令与结果。
15. 调试：先复现并记录现场（视口宽度、控制台报错、复现步骤）再改代码，未复现的假设不当结论。
16. 调研写作：关键事实带来源与日期，推断标【推断】，不编造 URL、数字、引语；执行者流程见 `collab/PROTOCOL.md`。
